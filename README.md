# Frontend Developer Tasks

A collection of frontend practice tasks covering HTML, CSS, JavaScript, responsive layouts, form validation, React, and browser-side state.

## Tasks
1. Static webpage structure and styling
2. Form creation and client-side validation
3. React to-do list with dynamic state
4. Responsive navigation and image gallery

## Skills practiced
HTML, CSS, JavaScript, React components/state, Local Storage, responsive navigation, and lightbox-style interactions.

## Running locally
Static tasks can be opened directly in a browser. For a React task with its own package configuration, use its local npm install and npm start workflow.

## Purpose
This repository is a practical frontend exercise set rather than a single production application.
